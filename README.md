# Hospital & Healthcare Website - NovaCare (Group 3)

A healthcare website with 24/7 trauma emergency bar, hospital background, 6 medical departments, doctor profiles with OPD hours, wellness guides, and online appointment booking desk.

## Project Overview
- **Technology Stack**: 100% Pure HTML5 and CSS3 (Zero JavaScript)
- **Design Philosophy**: Semantic, fully responsive (desktop, tablet, mobile), modern typography, and clean layout structure.

## File Structure
- index.html: Semantic webpage structure and content.
- style.css: Comprehensive responsive styles, CSS variables, and modern visual design.

## How to Run Locally
1. Clone the repository:
   ``bash
   git clone https://github.com/saisutha/hospital-healthcare-website.git
   ``
2. Open index.html in any web browser.
